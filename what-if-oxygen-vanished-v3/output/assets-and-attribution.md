# Figures, sources, assets and licences — "What If Oxygen Vanished?" v3 (atom-zoom quiz)

**Thought experiment.** Matter cannot simply disappear. Tags on screen: **REAL DATA** (published value) ·
**ROUGH ESTIMATE · OUR CALCULATION** · **THOUGHT EXPERIMENT**. Page-level citations were not re-checked.

## How v3 differs from the reference short the user supplied

v2 borrowed that video's format closely (italic serif captions, a left-side serif readout, a raised waterfront view
with a centred bridge, a dark serif end card, and one near-verbatim opening line). v3 removes all of those:

| Reference device | v3 replacement |
|---|---|
| Poetic present-tense narration captions | Interactive 5-question quiz (A/B/C, thinking timer, reveal) |
| Left-side serif readout (label + big number) | Top-right **oxygen meter** with an element tile, plus coloured REAL DATA / ESTIMATE / THOUGHT EXPERIMENT badges |
| Italic serif typography | Inter / Inter Display, matching this channel's H and O episodes |
| Raised view down a promenade, bridge centred | Eye-level view from the Kuching waterfront across the river to a golden-roofed assembly building and an S-shaped footbridge (stylised, inspired by Kuching) |
| Calm → countdown → disaster | Cold open on the aftermath → rewind → quiz → "3 · 2 · 1" → each object shown one by one with an **atom-zoom inset** |
| Dark serif end card | Periodic table with H (episode 1) and O crossed out → "Which element should we delete next?" |

No footage, art, audio, text or branding from the reference is used. Every line of on-screen text is new.
