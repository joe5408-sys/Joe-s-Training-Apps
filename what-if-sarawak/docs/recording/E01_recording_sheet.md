# Recording sheet — E01: What If the Brooke Family Still Governed Sarawak?

Record on any phone voice-memo app. You don't need a studio.

## How to record
1. Quiet room with soft things around (a bedroom is better than a kitchen). Fan and aircon off.
2. Phone 15–20 cm from your mouth, slightly to the side. Talk normally, not too loud.
3. **Easiest:** one memo per character. Say the lines in the order below, with a **2-second pause** between lines. Name the file `<character>_all` (e.g. `auntie_all.m4a`). If you make a mistake, stop and start that memo again: an extra take confuses the automatic splitting.
4. **Or:** one memo per line, named by the ID in the table (e.g. `a01.m4a`). Use this for any line you want to re-take later.
5. Send the files: attach them in this chat, or upload them on GitHub to `what-if-sarawak/assets/voiceover/recorded/e01/` on the working branch.
6. Say it the way you would really say it. Change words if a line sounds unnatural to you, and tell me the new wording so the subtitles match.

Lines you don't record keep the synthetic voice, so you can do the most important characters first (Auntie and the narrator).
